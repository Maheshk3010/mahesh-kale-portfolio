# Mahesh Kale — Analytics Control Room

## Direction
Rebuild the single-page portfolio as a cinematic, editorial analytics workspace. The visual narrative follows one operating pipeline:

```text
RAW DATA → VALIDATE → ANALYZE → KPI → DASHBOARD → REPORT → BUSINESS ACTION
```

The site will position Mahesh only for **Data Analyst** and **MIS Executive** roles. Machine-learning work remains secondary and moves below the main analytics portfolio.

## Page structure
1. **Home / Command Center**
   - Staged introduction: MAHESH KALE → DATA ANALYST | MIS EXECUTIVE.
   - Immediate tools and work scope: SQL, Power BI, Advanced Excel, Python; analysis, MIS reporting, KPI dashboards, reporting automation.
   - Verified proof: 50K+ records, 7K+ customer records, internships, completed projects.
   - Editorial control-room scene built from subtle grid lines, data movement, query rows, restrained KPI modules, and the analytics pipeline.
   - Actions: View My Work, Download Resume placeholder, GitHub, LinkedIn.

2. **The Analytics Workflow**
   - Six connected stages: Collect, Clean, Validate, Analyze, Visualize, Report.
   - Each stage shows a concise job-focused explanation and relevant tools.
   - No motivational or “Why Hire Me” copy.

3. **Selected Analytics Work**
   - Large, varied editorial case-study panels rather than repeated cards.
   - Prioritize the existing Sales Dashboard and SQL Sales Analysis entries.
   - Each panel provides structured fields for Business Question, Data, Process, Tools, Output, Key Findings, Result, and Evidence.
   - Unsupported findings, results, screenshots, demos, and case-study URLs appear as clearly labelled “Awaiting verified evidence” placeholders.
   - Repository mismatches will be disclosed as unavailable evidence rather than silently linked.
   - Existing ML projects move to a compact “Additional Technical Work” area.
   - SQL warehouse / ETL work will not be presented as completed until verified content exists.

4. **Reporting & MIS**
   - Dedicated source-to-management-report flow.
   - Four capability chapters: MIS Reporting, KPI Reporting, Data Validation, Reporting Automation.
   - Emphasize reconciliation, accuracy, repeatable reporting, Power BI, Excel, SQL, and management insight.

5. **Analytics Stack**
   - Workflow-organized rows: Analyze, Report, Validate, Visualize, Automate, Supporting.
   - No generic skills grid or skill pop-up catalogue.

6. **Field Experience**
   - Drawn timeline for ExcelR Solutions, Sysslan IT Solutions, and Codveda Technologies.
   - Structure each chapter as Role, Company, Dates, Location, Data, Work, Deliverables.
   - Unknown dates/locations/deliverables remain explicitly unverified; no achievements are invented.

7. **Education & Credentials**
   - Concise B.Sc. Computer Science and professional training entries.
   - Compact credentials register; missing dates and verification links are labelled accordingly.

8. **Behind the Analysis**
   - Later-page human introduction using only existing factual background.
   - Remove unsupported personality claims and generic self-description.

9. **Contact / Final Report**
   - Focused closing transition for Data Analyst and MIS Executive opportunities.
   - Keep verified email, phone, GitHub, and LinkedIn.
   - Resume action remains a clearly disabled/pending control until a real file or URL exists.

## Visual and motion system
- Dark graphite control-room canvas with cyan/blue accent, precise borders, restrained lighting, and analytical grid geometry.
- Editorial typography, oversized section numbers, monospaced operational labels, and asymmetric report layouts.
- Avoid glass-card grids, decorative blobs, fake charts, stock media, random icons, excessive neon, and repetitive rounded containers.
- Hero entrance runs as a staged workstation activation; scroll sections use restrained reveal, timeline draw, image masks, and stagger.
- Dashboard fragments communicate process/state only and will not imply fabricated business data.
- Every animation respects reduced-motion preferences and preserves reading order.

## Navigation and accessibility
- Navigation: Home, Work, MIS, Skills, Experience, Education, About, Contact.
- Add a proper keyboard-accessible mobile menu with close behavior and focus management.
- Maintain visible focus, semantic landmarks, one H1, readable contrast, and touch-safe controls.
- Ensure all dialogs or overlays retained from existing functionality have keyboard dismissal and focus return.
